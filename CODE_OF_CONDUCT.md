# Code of conduct

Everyone who takes part in this project, in issues, pull requests or reviews, agrees to the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour to [makeathon@tum-ai.com](mailto:makeathon@tum-ai.com). Every
report is reviewed confidentially by the Makeathon team.
